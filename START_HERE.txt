MEDIMEMORY — START HERE (Windows)
================================

1. Install Python 3.10+ (3.11 recommended) and Node.js LTS.
2. Extract this ZIP to a normal folder (not inside Program Files or a protected folder).
3. Double-click start_all.bat. The first launch installs dependencies and needs internet access.
4. Wait for both terminal windows to finish setup. Keep both windows open.
5. Open http://localhost:5173 in your browser.
6. Choose the demo login or enter:
      Email: demo@medimemory.test
      Password: Demo123!
7. Backend API docs: http://127.0.0.1:8000/docs

If Windows blocks a script, right-click the ZIP > Properties > Unblock (if shown),
then extract again. Do not close the backend or frontend terminal windows while testing.

OPTIONAL AI / VOICE SETUP
-------------------------
Copy backend/.env.example to backend/.env (the launcher creates it on first run).
Add your own ElevenLabs API key and voice ID for real STT/TTS calls.
Add your own OpenAI API key/model for optional LLM-backed responses.
Never put API keys in frontend files or commit .env files to GitHub.

IMPORTANT LIMITATIONS
---------------------
This is a hackathon prototype, not a medical device or clinical decision system.
Use fictional data only. It does not diagnose, prescribe, or replace a clinician.
OCR is not included. Image uploads are not automatically read as text.
Caregiver access is an invitation-record prototype; it does not provide a separate
caregiver account or grant external access. Reminders are in-app while the app is open.
ElevenLabs and LLM features require valid API keys and internet access.
